# 🧠 JS Client-Side Reverse Engineering Archive

A curated collection of online tools and resources for JavaScript analysis, deobfuscation, formatting, and obfuscation research. This repo is useful for understanding how modern client-side JS is transformed, protected, and reverse engineered.

---

## 🔧 Deobfuscation & Analysis

### 🔗 WebCrack
https://webcrack.netlify.app/  
A web-based tool for analyzing and deobfuscating JavaScript code. Useful for unpacking and simplifying complex or protected scripts.

### 🔗 Deobfuscate
https://deobfuscate.io/  
Automatically simplifies obfuscated JavaScript using common static analysis techniques like string decoding and control-flow cleanup.

---

## 🛡️ Obfuscation & Protection

### 🔗 Obfuscator
https://obfuscator.io/  
Popular JS obfuscation tool using control-flow flattening, string encoding, dead code injection, and identifier renaming.

### 🔗 JS-Confuser
https://js-confuser.com/  
Advanced obfuscation service focused on heavily protecting JavaScript against reverse engineering.

### 🔗 MeowShield
https://meowshield.com/  
JavaScript protection tool designed to prevent copying and analysis of client-side code.

---

## 🎨 Formatting & Minification

### 🔗 Beautifier
https://beautifier.io/  
Fast online code formatter for JavaScript, HTML, and CSS.

### 🔗 HTMLStrip Unminify JS
https://www.htmlstrip.com/unminify-javascript/  
Restores readability of minified or compressed JavaScript code.

### 🔗 UglifyJS Online
https://skalman.github.io/UglifyJS-online/  
Browser-based JS minifier using UglifyJS.

### 🔗 Terser Playground
https://try.terser.org/  
Online playground for testing JavaScript minification and compression with Terser.

---

## 🌳 AST & Code Analysis

### 🔗 AST Explorer
https://astexplorer.net/  
Interactive tool for visualizing Abstract Syntax Trees (AST) from JavaScript code.

### 🔗 Babel REPL
https://babeljs.io/repl  
Real-time JS transpilation tool used to study AST-based transformations and Babel behavior.
